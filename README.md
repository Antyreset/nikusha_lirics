Сину мій рідненький,
Ти пішов захищати нас.
Минуло вже чимало часу,
Та щодня молюся я за тебе.

Люблю тебе більше, ніж життя,
Щодня чекаю твого дзвінка.
Ти — ангел мій, тільки но без крил.

Ти там, в холодному окопі,
Щоб я могла спокійно спати в ліжку.
Скажи, чи маєш ти що їсти?
Чи вдається хоч трохи поспати?

Я хвилююся с кожним днем за тебе все більше,
Та вірю: ти сильний, ти витримаєш усе.
І завжди пам’ятай — мама тебе безмежно любить.
